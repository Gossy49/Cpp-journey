# C++ Journey

This repository documents my learning journey in C++ as I build a strong foundation for embedded systems and microcontroller development.

## Objective

The goal of this repository is to:
- Develop a solid understanding of C++ fundamentals
- Practice problem solving through small programs
- Build consistency in writing and structuring code
- Prepare for work in embedded systems and low-level programming

## Structure

The repository is organized by learning stages. eg ("Day1, Day2, etc....")

Each folder contains:
- A C++ source file (`.cpp`)
- A README explaining what was learned

## Topics Covered

- Basic program structure
- Input and output (`std::cin`, `std::cout`)
- Variables and data types
- Strings
- Conditional statements (`if`, `else if`, `else`)
- Simple program logic

## How to Run the Programs

All programs are compiled using `g++` on a Linux system.

### Compile
```bash
g++ filename.cpp -o output_name

Run 
./output_name
